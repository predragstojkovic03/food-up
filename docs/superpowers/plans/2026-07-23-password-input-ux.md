# Password Input UX Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add confirm password fields to both registration forms and show/hide password toggles to all password fields across the app.

**Architecture:** Install shadcn `input-group`, create a shared `PasswordInput` component in `src/components/ui/` that wraps `InputGroupInput` + `InputGroupAddon` with a lucide Eye/EyeOff toggle button managing its own visibility state. Registration schemas gain a `confirmPassword` field with cross-field match validation via `.refine()`. All `<Input type="password">` usages are swapped for `<PasswordInput>`.

**Tech Stack:** React 19, shadcn/ui (`base-nova` style, v4), lucide-react, React Hook Form, Zod (v3 compat API via `zod/v3`), i18next (EN + SR)

### Task 2: Create PasswordInput component

**Files:**
- Create: `apps/web/src/components/ui/password-input.tsx`

**Implementation A — using shadcn InputGroup (if Task 1 succeeded):**

- [ ] **Step 1: Create the component**

Create `apps/web/src/components/ui/password-input.tsx`:

```tsx
import * as React from 'react'
import { Eye, EyeOff } from 'lucide-react'
import { useState } from 'react'
import {
  InputGroup,
  InputGroupAddon,
  InputGroupInput,
} from '@/components/ui/input-group'

function PasswordInput({ className, ...props }: React.ComponentProps<'input'>) {
  const [show, setShow] = useState(false)

  return (
    <InputGroup>
      <InputGroupInput
        type={show ? 'text' : 'password'}
        className={className}
        {...props}
      />
      <InputGroupAddon align="inline-end">
        <button
          type="button"
          onClick={() => setShow((s) => !s)}
          className="flex items-center text-muted-foreground hover:text-foreground"
          aria-label={show ? 'Hide password' : 'Show password'}
          tabIndex={-1}
        >
          {show ? <EyeOff className="h-4 w-4" /> : <Eye className="h-4 w-4" />}
        </button>
      </InputGroupAddon>
    </InputGroup>
  )
}

export { PasswordInput }
```

**Implementation B — manual fallback (if Task 1 failed):**

- [ ] **Step 1: Create the component**

Create `apps/web/src/components/ui/password-input.tsx`:

```tsx
import * as React from 'react'
import { Eye, EyeOff } from 'lucide-react'
import { useState } from 'react'
import { cn } from '@/lib/utils'
import { Input } from '@/components/ui/input'

function PasswordInput({ className, ...props }: React.ComponentProps<'input'>) {
  const [show, setShow] = useState(false)

  return (
    <div className="relative">
      <Input
        type={show ? 'text' : 'password'}
        className={cn('pr-9', className)}
        {...props}
      />
      <button
        type="button"
        onClick={() => setShow((s) => !s)}
        className="absolute inset-y-0 right-0 flex items-center pr-2.5 text-muted-foreground hover:text-foreground"
        aria-label={show ? 'Hide password' : 'Show password'}
        tabIndex={-1}
      >
        {show ? <EyeOff className="h-4 w-4" /> : <Eye className="h-4 w-4" />}
      </button>
    </div>
  )
}

export { PasswordInput }
```
